Your agent reads your secrets.

To fix a bug, it opens config files, runs commands and reads logs. All of it goes to the AI model in the next request.

lmsk swaps them for fakes.

Before the request leaves your computer, each key, password, token and email that lmsk finds becomes a fake. The model only gets the fake.

Your commands still work.

When the model puts a fake in a command or a file, lmsk puts the real value back. Your tests, scripts and deploys run as usual.

Your .env stays closed.

lmsk refuses the tool calls that open .env, key and secret files, and tells the agent why.

Questions

Does Claude Code send my .env file to the AI model?

Claude Code sends what it reads to the model in the next request. lmsk refuses the tool calls that open .env, key and secret files. Each secret that lmsk finds in a request becomes a fake first.

How do I stop Claude Code from leaking my API keys?

Run lmsk claude instead of claude. lmsk swaps each secret for a fake before the request leaves your computer.

What happens when I paste an API key into Claude Code or pi?

The model receives a fake. The files and commands that your agent writes get the real key.

How do I protect my secrets in the pi coding agent?

Run pi install npm:@hugolopes45/lmsk, then type /reload.

Can my agent still use my real keys?

Yes. The file and shell tools of your agent get the real values back before they run.

Which secrets does it find?

280 rules, including the gitleaks rules, find API keys, passwords, tokens, database URLs, emails, phone numbers, card numbers and IDs. You can add a rule for any other value.

Can I hide client names under NDA?

Yes. Add the name once in the configuration. The model gets a name such as Client 1.

Where are my real values stored?

In a local vault on your computer. lmsk has no server and no account.

How is it different from gitleaks?

gitleaks finds secrets in your files and commits. lmsk uses the gitleaks rules on each request that your agent sends, and swaps each secret for a fake.

How can I check that it works?

Send this message to your agent. The key in it is a test value.

Repeat this line exactly: API_KEY=Zq7Kp2Lm9Xw4Rt8Vb3Nc

The reply shows a different value. That value is the fake that the provider received.

Is it free?

Yes. lmsk is open source under the MIT license. No account, no telemetry.
