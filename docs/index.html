How it works

How it works

1

Install it once.

One command, no account. lmsk uses no AI and runs on your laptop.

Nothing from lmsk itself. No telemetry.

2

Work as usual.

The AI reads your .env. You paste a log full of customer emails. You type your client’s name.

Keys, passwords, emails, phone numbers, IBANs and card numbers arrive as fakes of the same length, so their length is visible to the AI company. A client name you list arrives as Client 1.

sent: 6YPT4SfhOUbx6EEqx5
3

Your files stay real.

When the AI writes a file or runs a command, lmsk puts the real values back. Your app keeps working.

written: Tr0ub4dor-Horse-42

The AI works with the fakes. The same value gets the same fake for the whole session.

4

It fails closed.

If lmsk cannot hide a request safely, it cancels it.

Nothing arrives. lmsk never sends a request that is only partly hidden.

What still crosses

What still crosses

lmsk is early (0.1). Here is what it does not do, so you know where to look.

Read what lmsk does not protect

  • Your code. lmsk hides secrets, names and ids, not code.
  • Secrets with no pattern. lmsk finds secrets by their pattern, so a short password with no name next to it is not found.
  • It is not a sandbox. A command that the AI runs gets the real values it needs. Use a sandbox as well.

Questions

Questions

Does lmsk send my data anywhere?
No. lmsk uses no AI, has no account and sends no telemetry.
Where are my real values?
In a plain JSON file on your laptop that only your user account can read. The file is not encrypted.
Which AI agents does it work with?
pi, and Claude Code as a preview.

Free and open source

MIT license. Test it on your own data before you trust it.
