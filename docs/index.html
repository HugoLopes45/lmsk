lmsk

Use AI on your code. Keep your passwords to yourself.

lmsk swaps your passwords, keys and emails for fakes before your AI coding assistant sends anything. When the AI edits a file or runs a command, lmsk puts the real values back, so your project keeps working. Free, and nothing to set up.

Install in one command

What the AI company receives

On your computer

DB_PASSWORD=Tr0ub4dor-Horse-42
CONTACT=jane.doe@example.com

What the AI company gets

DB_PASSWORD=6YPT4SfhOUbx6EEqx5
CONTACT=ptfe.rol@dweervr.xtw

The fakes are random. Each fake keeps the length of its real value, and the same value gets the same fake for the whole session.

How it works

  1. Install it once. One command, no account.
  2. Work as usual. Before each request leaves your computer, lmsk replaces passwords, keys, emails, phone numbers, IBANs and card numbers with fakes. Add your client's name once, and it becomes Client 1.
  3. Your files stay real. When the AI writes a file or runs a command, lmsk puts the real values back.

If lmsk cannot hide a request safely, it cancels the request. It never sends a request that is only partly hidden.

Questions

Does my code still go to the AI company?
Yes. lmsk hides secrets, names and ids, not your code.
Does lmsk catch every secret?
No. It finds secrets by their pattern, so a short password with no name next to it is not found. Read what lmsk does not protect.
Does lmsk send my data anywhere?
No. lmsk uses no AI, has no account and sends no telemetry. Your real values stay in a file that only your user account can read.
Is it a sandbox?
No. A command that the AI runs gets the real values it needs. Use a sandbox as well.
Which AI assistants does it work with?
pi, and Claude Code as a preview.
